AI Resume Analyzer

An AI-powered Python application that analyzes PDF resumes, identifies strengths and weaknesses, and generates actionable suggestions using Google Gemini AI.

Project Overview

AI Resume Analyzer helps users understand and improve their resumes using generative AI. Users upload a PDF resume, and the application extracts its content and sends it to Google's Gemini model for analysis.

Key Features

  • Upload resumes in PDF format.
  • Extract text from PDF documents using pypdf.
  • Analyze technical skills, education and experience.
  • Identify resume strengths and weaknesses.
  • Generate AI-powered improvement suggestions.
  • Download the generated analysis report.
  • FastAPI endpoints for resume analysis and API health checks.

Technologies Used

  • Python
  • Streamlit
  • FastAPI
  • Uvicorn
  • Google Gemini API
  • Google GenAI SDK
  • pypdf
  • python-dotenv

Project Information

Category: AI Application

Platform: Web Application / REST API

Language: Python

AI Integration: Gemini API

How It Works

  1. User uploads a PDF resume.
  2. The application extracts text from the PDF.
  3. Extracted content is processed for AI analysis.
  4. Gemini generates feedback and suggestions.
  5. The user can review and download the analysis report.
