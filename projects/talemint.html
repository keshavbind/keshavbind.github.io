TaleMint

A digital publishing platform that allows users to discover and publish short stories, poetry and lyrics through an Android application.

Project Overview

TaleMint is an Android application designed to provide a platform for discovering and publishing creative written content. Users can explore different categories of content and create their own publications. The application uses Firebase for backend services and follows MVVM architecture to organize its components.

Key Features

  • User authentication and profile management.
  • Explore published creative content.
  • Discover stories, poetry and lyrics.
  • Browse content through categories.
  • Create and publish written content.
  • Store user and publication data using Firebase Firestore.
  • Organize application code using MVVM architecture.

Technologies Used

  • Kotlin
  • Android Studio
  • Firebase Authentication
  • Cloud Firestore
  • Retrofit
  • MVVM Architecture
  • Android XML

Project Information

Category: Android Application

Platform: Android

Language: Kotlin

Backend: Firebase

Architecture: MVVM

How It Works

  1. Users register or log in to the application.
  2. Users explore content through the home screen and categories.
  3. Published content is retrieved from Firebase Firestore.
  4. Users can create and publish their own content.
  5. Content and user information are managed through backend services.
