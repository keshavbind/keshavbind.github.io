ChatApp

A modern, real-time Android messaging application built using Kotlin, Firebase Authentication, Cloud Firestore and Material Design.

Project Overview

ChatApp is an Android messaging application that allows users to register, log in and communicate with other registered users in real time. Firebase Authentication handles user accounts, while Cloud Firestore stores and synchronizes chat messages.

Key Features

  • User registration and login using Firebase Authentication.
  • Real-time message sending and receiving.
  • Contact list displaying registered users.
  • Chat rooms for individual conversations.
  • Message previews in the users list.
  • Custom sender and receiver chat bubbles.
  • Initial-based user avatars.
  • Logout functionality.

Technologies Used

  • Kotlin
  • Android Studio
  • Firebase Authentication
  • Cloud Firestore
  • RecyclerView
  • XML Layouts
  • Material Design
  • Gradle Kotlin DSL

Project Information

Category: Android Application

Platform: Android

Language: Kotlin

Backend: Firebase

Database: Cloud Firestore

How It Works

  1. Users register or log in using their email and password.
  2. Firebase Authentication verifies user accounts.
  3. The application displays a list of registered users.
  4. Users select a contact to open a chat room.
  5. Messages are stored in Cloud Firestore.
  6. Firestore snapshot listeners update conversations in real time.
