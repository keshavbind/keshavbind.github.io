Brewkery

A coffee and bakery ordering Android application that allows users to explore products, customize selections and manage their ordering experience.

Project Overview

Brewkery is a native Android application developed using Kotlin and XML. It provides a coffee and bakery shopping experience with product browsing and API-based data integration. The application uses Retrofit to communicate with REST APIs and follows MVVM architecture to organize application components.

Key Features

  • Browse coffee and bakery products.
  • Load product information from REST APIs.
  • Display products using RecyclerView.
  • View individual product details.
  • Customize product selections.
  • Manage the ordering and cart experience.
  • Load product images using Glide.

Technologies Used

  • Kotlin
  • Android XML
  • MVVM Architecture
  • Retrofit
  • REST APIs
  • Kotlin Coroutines
  • RecyclerView
  • Glide

Project Information

Category: Android Application

Platform: Android

Language: Kotlin

Architecture: MVVM

Networking: Retrofit and REST APIs

How It Works

  1. The application requests product data from REST API endpoints.
  2. Retrofit handles API communication.
  3. Coroutines support asynchronous network operations.
  4. Product information is displayed using RecyclerView.
  5. Glide loads product images.
  6. Users explore products and interact with the ordering interface.
