GeminiStock AI

An intelligent inventory management agent that allows users to manage products and stock levels through natural-language commands using Google Gemini AI and MySQL.

Project Overview

GeminiStock AI is an AI-powered inventory management system built using Python, MySQL and Google's Gemini API. It uses Gemini function calling to understand user instructions and execute inventory operations through Python functions connected to a MySQL database.

Key Features

  • Add new products to inventory.
  • View available products.
  • Update product quantity and price.
  • Delete products with user confirmation.
  • Search products by ID or name.
  • Identify products with low stock.
  • Set and update minimum stock levels.
  • Manage inventory using natural-language commands.

Technologies Used

  • Python
  • Google Gemini API
  • Gemini Function Calling
  • MySQL
  • MySQL Connector for Python
  • Python Dotenv

Project Information

Category: AI Application

Platform: Python Application

Database: MySQL

AI Integration: Gemini Function Calling

How It Works

  1. The user enters an inventory instruction in natural language.
  2. Gemini interprets the request and selects the appropriate function.
  3. Python executes the selected inventory operation.
  4. The application interacts with the MySQL database.
  5. The operation result is returned to Gemini and presented to the user.
